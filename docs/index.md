# Rosorah Studio

Free, open-source streaming and recording software for Windows and Linux.

Create scenes with game capture, cameras, media, and browser sources. Compose multiple canvases, manage audio, record video, and stream to your chosen destinations. Connect supported platforms to manage broadcasts, view chat and activity, and run alerts and automations.

Rosorah Studio is under active development. Available features and platform support vary by release; see the repository and release notes for current details.
